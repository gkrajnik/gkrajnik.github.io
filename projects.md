## NFL game outcome predictor {#nfl-predictor}

*Three-person group project · 2026*

I worked with two teammates to build a Python program that estimates NFL regular-season game outcomes using historical weekly offensive and defensive statistics. The program compares team performance through prediction functions and a point-based scoring approach, then displays estimated home and away win probabilities.

### What I worked on

- Cleaning and analyzing team datasets with pandas and NumPy.
- Creating home and away probability visualizations with Matplotlib.
- Using linear regression to explore relationships between yearly team statistics and wins.

The project gave me experience working collaboratively, turning sports data into predictions, and explaining results through visualizations.

**Tools:** Python, pandas, NumPy, Matplotlib
